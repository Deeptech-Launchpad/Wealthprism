## Extending — the pattern every ticket follows
1. Add the endpoint to `api/openapi.yaml`.
2. Put the calculation in `packages/finance` with a test.
3. Implement the route in `apps/api/src/routes/*.ts` inside `withFamily()`; add an integration test in `apps/api/test`.
4. Add the web page (copy `Dashboard.tsx`) and the mobile screen (copy `Tasks.tsx`); both use the same client helpers.
